# GPT Image Paint 中文版

基于 [quasa0/paint.quasa0.com](https://github.com/quasa0/paint.quasa0.com) 的独立中文版本。保留原版画布、绘图工具与版本历史，加入中文交互、自定义图片模型和兼容 OpenAI 图片编辑协议的中转站接入。

## 本地启动

需要 Node.js 24 LTS 与 npm。

1. 安装依赖：运行 `npm ci`。
2. 双击 `start.cmd`，或运行 `npm run dev -- --host 127.0.0.1 --port 8768 --strictPort`。
3. 打开 http://127.0.0.1:8768/app/。

如需本机代理，将 `.env.example` 复制为 `.env.local`，按需设置 `PAINT_HTTP_PROXY`；不用代理可留空。修改后重启本地服务。

## 图片与局部修改

- 通过文件菜单、拖入或粘贴导入图片。
- 支持矩形与套索选区、画笔、橡皮、填充、取色、文字、线条、曲线及形状；选区支持移动、缩放、旋转、翻转与复制。
- 在“API / 中转站设置”填写服务地址、API Key 和实际模型 ID，不限制为某一个图片模型。
- 选择区域，输入修改要求后提交；可开启周围上下文，模型返回的图像写回选区。
- 对 `img.937ai.chat` 的无 mask 编辑链路做了适配；其他服务按实际能力选择模式。
- 本地开发服务通过同源转发调用图片编辑接口，避免中转站不支持浏览器 CORS 的问题。静态部署后的调用需要服务支持 CORS；`npm run preview` 不提供该开发转发接口。

支持下载 PNG、JPEG、WebP 等图片，不包含科研工作台的图片转 PPT 功能。原项目的可选登录链路仍保留；自定义中转推荐使用 API Key 方式。

## 数据与配置

图稿和历史保存在浏览器 IndexedDB；API Key 与设置保存在当前站点的浏览器存储中。换端口、换浏览器或清除站点数据后不会自动继承。请自行导出需要保留的图片。

仓库不包含本机 Key、登录令牌、图稿、node_modules 或 .env.local。本地转发只用于回环地址上的个人使用。已移除上游用于调试读取本机 Key / Codex 登录凭据的开发辅助端点。
